# Webinario 8.2 · Urban Routes — Pruebas con Pytest

Repositorio de práctica del webinario 8.2 (Sprint 8).

## Antes del webinario

1. Ten PyCharm con Pytest instalado y configurado como *Default test runner* (lección 8.3.1).
2. Clona este repositorio: en PyCharm, **File → Project from Version Control**, pega la URL y haz clic en **Clone**.

> En este webinario solo vas a ejecutar y escribir pruebas en tu computadora: no necesitas hacer push.

## Archivos

| Archivo | Para qué lo usamos |
|---|---|
| `tests/test_descubrimiento.py` | Quiz: ¿qué funciones recolecta Pytest? |
| `tests/test_tiempos_llegada.py` | Ejecutar pruebas e interpretar el resultado (tarea guiada) |
| `tests/test_propina_practica.py` | Completar un test a partir de un caso manual (práctica en la sala principal) |
